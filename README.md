# Include Graph

## Описание
Расширение для Visual Studio Code, которое строит граф зависимостей C++ проекта. Граф показывает, какие файлы подключают друг друга директивами `#include "..."`, и отображается в боковой панели в виде дерева. Это помогает быстро разобраться в структуре проекта и найти циклические зависимости.

## Возможности

- Отображение дерева зависимостей для файлов `.cpp`, `.h` и `.hpp`.
- Обнаружение циклических зависимостей: такие файлы помечаются `(cycle)`.
- Открытие файла в редакторе по клику в дереве.
- Автоматическое обновление дерева при сохранении файла.
- Команда `Include Graph: Refresh` — принудительное обновление дерева.

## Запуск

1. Выполнить `npm install`.
2. Нажать `F5` — откроется окно Extension Development Host.
3. Открыть в нём папку с C++ проектом.
4. Выбрать значок Include Graph на боковой панели.

## Файлы в `src`

| Файл | Назначение |
| --- | --- |
| `extension.ts` | Точка входа: создаёт панель, регистрирует команду обновления, перестраивает дерево при запуске и при сохранении файла. |
| `workspace.ts` | `GetData`: находит файлы проекта и возвращает карту «путь → содержимое». |
| `parser.ts` | `GetPaths`: извлекает из текста файла пути из `#include "..."`. |
| `resolve-absolute-path.ts` | `GetAbsolutePath`: преобразует путь из `#include` в абсолютный путь файла. |
| `graph.ts` | `BuildGraph`: строит граф зависимостей (`include` и `included_by`). |
| `tree-provider.ts` | `NodeFile` и `FilesProvider`: отображение графа в виде дерева. |
